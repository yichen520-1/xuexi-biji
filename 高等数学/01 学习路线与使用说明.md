<span style="background-color:rgb(255, 249, 227)">一：建议路线</span>

1. **打基础**：函数、三角与反三角、极限、连续。尤其练习“先检查定义域与趋近条件”。
2. **掌握局部变化**：导数、微分、中值定理、泰勒、单调性和极值。
3. **掌握累计**：不定积分、定积分、反常积分，以及面积、体积、弧长与做功。
4. **连接变化规律**：微分方程；从一阶方程练到常系数二阶方程。
5. **进入空间**：向量、直线、平面、曲面，再学多元极限、偏导、全微分和梯度。
6. **扩大累计对象**：重积分、曲线积分、曲面积分及格林、高斯、斯托克斯公式。
7. **理解无限过程**：数项级数、幂级数和傅里叶级数；一致收敛作为进一步理解的补充。

章节顺序用于知识依赖，不表示各校教学进度一致。上册通常对应第 1—7 章，下册对应第 8—12 章。第 7 章与级数在不同教材中可能放在其他位置。

<span style="background-color:rgb(255, 249, 227)">二：一篇笔记怎样学</span>

- 先看第一部分的“核心概念”，自己解释每个符号和条件。
- 阅读例题时，先遮住答案选方法，再核对每一步。
- 难点看“大白话再讲一遍”，随后回到严格表述，避免只记类比。
- 注意框记录不能随便省略的条件和易错点。
- 再读第二部分的“把原理讲透，把步骤写全”，把每一步为什么成立写在旁边。
- 最后独立完成第三部分的“自测与理解检查”，点击答案提示框再核对。

笔记并非只有摘要；概念、使用步骤与教学例题均放在各自知识点中。相邻笔记和相关概念使用双向链接连接，顶部可直接前后翻页。

<span style="background-color:rgb(255, 249, 227)">三：图与公式的约定</span>

- 所有三角函数默认弧度制。
- $\ln x$ 为自然对数；$C,C_1,C_2$ 为任意常数，若重新命名会在上下文说明。
- $o(h)$ 表示除以 $h$ 后趋于零；$O(h^k)$ 表示绝对值被常数倍 $|h|^k$ 控制。
- $\mathbf F$ 等粗体表示向量；$dA,dV,dS,ds$ 分别表示平面面积、体积、曲面面积和弧长微元。
- 凹凸采用“向上弯 $\cup$、向下弯 $\cap$”加二阶导数符号描述，避免不同教材中文命名差异。
- 球坐标的 $\varphi$ 是从正 $z$ 轴量起的极角，$\theta$ 是平面方位角。
- 图像只展示有限窗口；严格结论要靠定义、定理条件和推导，不以画面代替证明。

公式使用 Obsidian 原生数学语法，图像存放在“附件/图解”。建议用阅读视图查看完整排版，也可以在实时预览中阅读。自测答案是可折叠提示框，不需要安装插件。

<span style="background-color:rgb(255, 249, 227)">四：考试复习重点</span>

| 任务 | 先问自己 |
| --- | --- |
| 极限 | 能否直接代入？是什么未定式？是否发生相减抵消？ |
| 导数 | 是乘积、复合、隐函数还是参数方程？分段点是否需定义？ |
| 积分 | 识别哪种结构？上下限和定义域是否允许该操作？ |
| 最值 | 端点、驻点、不可导点、边界是否都检查了？ |
| 多元极限 | 是否对所有路径有效，而非只检查几个方向？ |
| 重积分 | 区域画对了吗？换元是否带雅可比？ |
| 曲线曲面积分 | 是第一型还是第二型？有无方向？场内部有无奇点？ |
| 级数 | 通项是否趋零？判别法条件是否满足？幂级数端点是否另查？ |

<span style="background-color:rgb(255, 249, 227)">七：从看懂到会做的四步</span>

### 1. 定义要能拆成对象、条件和结论

例如“可导必连续”中，对象是一个实函数在某内点的局部性质，条件是该点的有限导数存在，结论才是连续。不要把它误写成反命题“连续必可导”。

### 2. 例题要先判断结构再计算

先写“这是相减抵消的极限，要保留高阶项”或“这是带方向的通量，要先确定法线”，再动笔套公式。选错结构时，后面的计算再熟练也无法补救。

### 3. 验算必须与原问题连接

不定积分用求导核验；微分方程代回方程与初值；面积体积检查非负性和单位；多元极限检查估计是否对所有路径统一；幂级数重新代入端点。验算不是把同一套错误步骤再重复一遍。

### 4. 错题记录保留判断过程

建议记录“错误结论—漏掉的条件—一个反例—正确路线”。例如：把驻点当极值 → 漏了变号检查 → $x^3$ 在原点 → 改看导数左右符号。这样复习的是可迁移的方法，而不只是某道题的数字。
