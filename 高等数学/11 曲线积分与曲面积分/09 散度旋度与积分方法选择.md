# 散度旋度与积分方法选择

[[高等数学/11 曲线积分与曲面积分/08 斯托克斯公式与边界定向|← 斯托克斯公式与边界定向]] · [[高等数学/11 曲线积分与曲面积分/00 本章导航|本章导航]]

---

<span style="background-color:rgb(255, 249, 227)">一：概念、公式与基础例题</span>

### 1. 三个微分算子

- 梯度 $\nabla f$：标量函数变向量，指向最快增长方向。
- 散度 $\nabla\cdot\mathbf F$：向量场变标量，描述局部净流出。
- 旋度 $\nabla\times\mathbf F$：向量场变向量，描述局部旋转及轴向。

足够光滑时 $\nabla\times(\nabla f)=0$，$\nabla\cdot(\nabla\times\mathbf F)=0$，这是混合偏导可交换的结果。

### 2. 方法选择

| 题目结构 | 优先考虑 | 必查条件 |
| --- | --- | --- |
| 非闭曲线做功，有势函数 | 端点差 | 势函数覆盖整条路径 |
| 平面闭曲线环流 | 格林公式 | 区域内部光滑、边界方向 |
| 空间闭曲线环流 | 斯托克斯 | 旋度、跨接曲面与右手方向 |
| 闭曲面通量 | 高斯公式 | 内部无奇点、向外法线 |
| 开曲面通量 | 参数化或补面 | 补面符号与实际法线 |

### 3. 例题

**例 1：** $\mathbf F=(x,y,z)$ 的散度为 $3$，旋度为零：它向外发散，但不呈局部旋转。

**例 2：** $\mathbf G=(-y,x,0)$ 的散度为零，旋度为 $(0,0,2)$：它旋转，但没有局部净源。

### 4. 大白话再讲一遍

散度像小区域里有没有水源，旋度像放一只小叶轮会不会转。这两件事不同，一个场可以有源不转、旋转无源，也可以两者都有。

> [!warning] 注意
> “旋度为零推出存在全局势函数”需要区域条件；不能只套代数恒等式。选公式之前先看题目在累计长度、面积、做功还是通量。

<span style="background-color:rgb(255, 249, 227)">二：把原理讲透，把步骤写全</span>

### 1. 先认积分类型，再选定理

| 看到什么 | 首选思路 | 最容易漏什么 |
| --- | --- | --- |
| $f\,ds$ 或 $f\,dS$ | 弧长/面积参数化 | 真实长度或面积的缩放因子 |
| 非闭曲线 $\mathbf F\cdot d\mathbf r$ | 查势函数，再考虑参数化 | 势函数是否覆盖整条路径 |
| 闭曲线环流 | 平面格林、空间斯托克斯 | 奇点、边界方向、跨面条件 |
| 闭曲面通量 | 高斯 | 外法线与内部光滑性 |
| 开曲面通量 | 直接参数化或补面 | 补面通量的符号 |

### 2. 用两个场避免混淆散度与旋度

$\mathbf F=(x,y,z)$ 的散度是 $3$、旋度为零，说明向外流但不局部旋转。$\mathbf G=(-y,x,0)$ 的散度为零、旋度为 $(0,0,2)$，说明可旋转而无净源。

**统一检查顺序**：先看积分域闭不闭，再看积分方向，随后找场的奇点，最后才比较哪个公式计算量最小。形式最短的公式若不满足条件，反而是错误路线。

**恒等式的背景**：$\nabla\times\nabla f=0$ 与 $\nabla\cdot(\nabla\times\mathbf F)=0$ 来自混合偏导可交换，通常在二阶连续偏导条件下使用，不能把它们当成任何不光滑场上的无条件规则。

---

<span style="background-color:rgb(255, 249, 227)">三：自测与理解检查</span>

$\mathbf F=(y,z,x)$ 的散度与旋度是什么？

> [!success]- 答案
> 散度为 $0$；旋度为 $(-1,-1,-1)$。
