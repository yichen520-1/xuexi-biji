# 收敛数列的性质

[[高等数学/01 函数与极限/04 数列极限与严格定义|← 数列极限与严格定义]] · [[高等数学/01 函数与极限/00 本章导航|本章导航]] · [[高等数学/01 函数与极限/06 函数极限与左右极限|函数极限与左右极限 →]]

---

<span style="background-color:rgb(255, 249, 227)">一：概念、公式与基础例题</span>

### 1. 核心概念

若 $a_n\to A$，则有：

1. **唯一性**：同一个数列不能收敛到两个不同实数。
2. **有界性**：存在 $M$，使全部 $|a_n|\le M$。
3. **保号性**：若 $A>0$，则充分靠后的项为正；若 $A<0$，最终为负。
4. **子列性质**：任何子列都收敛到同一 $A$。

这些多是“收敛推出某性质”，不能随意倒过来。

### 2. 为什么成立

有界性的关键是把数列分为两段：取误差 $1$，足够靠后的项都落在 $(A-1,A+1)$ 内；前面仅有有限项，取它们绝对值的最大值即可统一控制。

唯一性可用三角不等式理解：如果 $A\ne B$，就各取一个半径小于 $|A-B|/2$ 的不相交邻域，不可能让同一尾项同时落进两个邻域。

### 3. 例题

**例 1：** $(-1)^n$ 有界，却不收敛，说明有界不是收敛的充分条件。

**例 2：** $a_n=1-100/n\to1$，但前面很多项是负数。保号性保证的是“最终为正”，不是“每一项为正”。

### 4. 大白话再讲一遍

既然整队人最终集中到某个小区域，就不可能有人无限远地跑出去。但队伍不跑远，也不等于集中到一个位置，可能一直在两个位置之间跳。

> [!warning] 注意
> 若每项 $a_n>0$ 且收敛，只能推出 $A\ge0$，不能推出 $A>0$。例如 $1/n>0$，极限却是 $0$。

---

<span style="background-color:rgb(255, 249, 227)">二：把原理讲透，把步骤写全</span>

### 1. 收敛为什么推出有界

设 $a_n\to A$。把误差固定为 $1$，则存在 $N$，使 $n>N$ 时 $|a_n-A|<1$，于是 $|a_n|<|A|+1$。开头只有有限项，取
$$M=\max\{|a_1|,\ldots,|a_N|,|A|+1\}$$
就能同时约束所有项。**后段由极限控制，前段由有限性控制**，这是很多证明的通用拆法。

### 2. 保号性到底保证什么

若 $a_n\to A>0$，取 $\varepsilon=A/2$，充分靠后时 $a_n>A/2>0$。它不是说前面所有项都正，也不是说极限为零时还能推出最终正。

| 命题 | 结论及理由 |
| --- | --- |
| 收敛必有界 | 正确，但有界不必收敛，如 $(-1)^n$ |
| 正数列的极限必正 | 错，$1/n\to0$；只能保证极限非负 |
| 改动有限项影响极限 | 不影响，定义只控制足够靠后的项 |
| 原数列收敛则子列同极限 | 正确，子列下标也趋于无穷 |

**唯一性的根本原因**：两个不同极限可以各取小于二者距离一半的误差带，后段不可能同时落入两个互不相交的带内。

---

<span style="background-color:rgb(255, 249, 227)">三：自测与理解检查</span>

若偶数项趋于 $2$、奇数项也趋于 $2$，能否推出全数列趋于 $2$？

> [!success]- 答案
> 能。对同一个误差，分别找到两个子列的门槛，再取足够大的总门槛，所有尾项都满足要求。
