# 初等函数与复合函数

<span style="background-color:rgb(255, 249, 227)">一：概念、公式与基础例题</span>

### 1. 核心概念

常见基本初等函数包括幂函数 $x^\alpha$、指数函数 $a^x$、对数函数 $\log_a x$、三角函数和反三角函数，其中指数与对数的底满足 $a>0,\ a\ne1$。

复合函数 $y=f(g(x))$ 表示先算内层 $u=g(x)$，再算外层 $y=f(u)$。定义域同时要求：$x$ 能进入 $g$，且 $g(x)$ 能进入 $f$。

### 2. 常用性质

指数与对数互为反函数：$\ln(e^x)=x$，$e^{\ln x}=x$（后一式要求 $x>0$）。$\arcsin x$ 的定义域为 $[-1,1]$，值域为 $[-\pi/2,\pi/2]$；$\arccos x$ 的值域为 $[0,\pi]$；$\arctan x$ 的值域为 $(-\pi/2,\pi/2)$。

三角函数在微积分中默认用**弧度制**。一周是 $2\pi$ 弧度；用角度制直接代入求导公式会缺少比例因子。

### 3. 例题

**例 1：** $y=\ln(1-x^2)$。外层要求真数为正，因此 $1-x^2>0$，定义域为 $(-1,1)$。

**例 2：** $\arcsin(\sin(3\pi/4))=\pi/4$，不是 $3\pi/4$，因为反正弦必须返回主值区间内的角。

### 4. 大白话再讲一遍

复合函数是两道工序：第一道处理完的产物，还要符合第二道的收货要求。反三角函数像“从三角函数值找角”，但同一个值对应很多角，所以必须约定只返回某一段中的角。

> [!warning] 注意
> $\ln(a+b)$ 不能拆成 $\ln a+\ln b$；只有乘积和商在真数为正时能拆。$\sqrt{x^2}=|x|$，不能无条件写成 $x$。

<span style="background-color:rgb(255, 249, 227)">二：把原理讲透，把步骤写全</span>

### 1. 复合函数是有顺序的流水线

$y=f(g(x))$ 的顺序是先算 $u=g(x)$，再算 $y=f(u)$。因此定义域同时要求：内层有意义，内层结果属于外层定义域。不能只分别求两层的定义域后机械相交。

### 2. 一步步找定义域

求 $y=\ln\sqrt{1-x^2}$ 的定义域。
1. 根号要求 $1-x^2\ge0$。
2. 对数要求它的整个自变量 $\sqrt{1-x^2}>0$，排除根号为零。
3. 合并为 $1-x^2>0$，得到 $-1<x<1$。

**拆层训练**：$\sin^2(3x+1)$ 是 $x\mapsto3x+1\mapsto\sin(3x+1)\mapsto[\sin(3x+1)]^2$。这个拆法直接决定以后链式法则的三个因子。

**不要混淆**：$f\circ g$ 一般不等于 $g\circ f$。如 $f(u)=u^2$、$g(x)=x+1$，前者是 $(x+1)^2$，后者是 $x^2+1$。初等函数由有限次允许的运算和复合得到，分类的目的不是背名称，而是识别定义域、连续性与可导性可用在哪些点。

<span style="background-color:rgb(255, 249, 227)">三：自测与理解检查</span>

$\sqrt{\ln x}$ 的定义域是什么？

> [!success]- 答案
> 要求 $x>0$ 且 $\ln x\ge0$，所以定义域为 $[1,+\infty)$。
