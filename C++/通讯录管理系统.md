## 1. 系统功能介绍及展示

通讯录是记录联系人信息的工具。本项目使用 C++ 控制台程序实现，最多保存 `1000` 名联系人。

每名联系人包含以下信息：

| 字段 | 数据类型 | 说明 |
| --- | --- | --- |
| 姓名 | `string` | 联系人的姓名 |
| 性别 | `int` | 约定 `1` 表示男，`2` 表示女 |
| 年龄 | `int` | 联系人的年龄 |
| 电话 | `string` | 电话可能包含前导 `0`，因此不用整数保存 |
| 地址 | `string` | 联系人的家庭住址 |

系统需要实现七个菜单选项：

1. 添加联系人
2. 显示联系人
3. 删除联系人
4. 查找联系人
5. 修改联系人
6. 清空联系人
0. 退出通讯录

> [!important] 本项目的核心
> - 用**结构体**描述一名联系人和整个通讯录。
> - 用**结构体数组**保存多名联系人。
> - 用 `m_Size` 记录数组中当前有效的联系人数量。
> - 将每项功能封装为独立函数，通过指针修改同一份通讯录数据。

## 2. 创建项目

在 Visual Studio 中创建一个 C++ 空项目，再添加源文件 `main.cpp`。

程序最初只需要准备输入输出和字符串头文件：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main()
{
    system("pause");
    return 0;
}
```

> [!note] 文件组织
> 视频中先在一个源文件内完成项目，便于初学者观察完整流程。项目变大后，可以把结构体与函数声明放入头文件，把各功能实现拆到单独的 `.cpp` 文件。

## 3. 菜单功能

菜单是用户选择功能的入口。将菜单输出封装成 `showMenu()`，主函数只负责调用它。

```cpp
void showMenu()
{
    cout << "***************************" << endl;
    cout << "*****  1. 添加联系人  *****" << endl;
    cout << "*****  2. 显示联系人  *****" << endl;
    cout << "*****  3. 删除联系人  *****" << endl;
    cout << "*****  4. 查找联系人  *****" << endl;
    cout << "*****  5. 修改联系人  *****" << endl;
    cout << "*****  6. 清空联系人  *****" << endl;
    cout << "*****  0. 退出通讯录  *****" << endl;
    cout << "***************************" << endl;
}
```

> [!tip] 函数封装
> 菜单内容属于一种独立行为，封装后可以反复调用，也能让 `main()` 的主流程更清楚。

## 4. 退出功能

程序使用 `while (true)` 持续显示菜单并接收选择，再使用 `switch` 分发不同功能。

```cpp
int select = 0;

while (true)
{
    showMenu();
    cin >> select;

    switch (select)
    {
    case 1: // 添加联系人
        break;
    case 2: // 显示联系人
        break;
    case 3: // 删除联系人
        break;
    case 4: // 查找联系人
        break;
    case 5: // 修改联系人
        break;
    case 6: // 清空联系人
        break;
    case 0:
        cout << "欢迎下次使用" << endl;
        system("pause");
        return 0;
    default:
        cout << "输入有误，请重新选择。" << endl;
        break;
    }
}
```

> [!important] 为什么用 `return 0`
> `break` 只能退出当前 `switch`，之后还会继续执行外层循环；`return 0` 会直接结束 `main()`，从而退出整个程序。

## 5. 添加联系人：结构体设计

### 5.1 联系人结构体

用 `Person` 将一名联系人的五项信息组合到一起：

```cpp
struct Person
{
    string m_Name;
    int m_Sex;
    int m_Age;
    string m_Phone;
    string m_Addr;
};
```

### 5.2 通讯录结构体

通讯录需要同时保存联系人数组和当前人数：

```cpp
#define MAX 1000

struct Addressbooks
{
    Person personArray[MAX];
    int m_Size;
};
```

### 5.3 创建并初始化通讯录

```cpp
Addressbooks abs;
abs.m_Size = 0;
```

> [!important] 数据设计重点
> `personArray` 的容量是 `MAX`，但真正有效的元素只有下标 `0` 到 `m_Size - 1`。新增、遍历、查找和删除都必须以 `m_Size` 为边界。

> [!warning] 必须初始化
> 如果没有将 `m_Size` 初始化为 `0`，其中可能是一个不确定值，后续数组访问可能越界。

## 6. 添加联系人：功能实现

添加联系人时，先判断通讯录是否已满；未满时，新联系人应写入 `personArray[m_Size]`，最后再将 `m_Size` 加 `1`。

```cpp
void addPerson(Addressbooks* abs)
{
    if (abs->m_Size == MAX)
    {
        cout << "通讯录已满，无法添加。" << endl;
        return;
    }

    int index = abs->m_Size;

    cout << "请输入姓名：" << endl;
    cin >> abs->personArray[index].m_Name;

    cout << "请输入性别：" << endl;
    cout << "1 -- 男" << endl;
    cout << "2 -- 女" << endl;

    while (true)
    {
        cin >> abs->personArray[index].m_Sex;
        if (abs->personArray[index].m_Sex == 1 ||
            abs->personArray[index].m_Sex == 2)
        {
            break;
        }
        cout << "输入有误，请重新输入：" << endl;
    }

    cout << "请输入年龄：" << endl;
    cin >> abs->personArray[index].m_Age;

    cout << "请输入联系电话：" << endl;
    cin >> abs->personArray[index].m_Phone;

    cout << "请输入家庭住址：" << endl;
    cin >> abs->personArray[index].m_Addr;

    abs->m_Size++;
    cout << "添加成功。" << endl;

    system("pause");
    system("cls");
}
```

在菜单的 `case 1` 中调用：

```cpp
case 1:
    addPerson(&abs);
    break;
```

> [!important] 指针与成员访问
> `addPerson(&abs)` 传入通讯录地址，函数参数使用 `Addressbooks*` 接收。指针访问结构体成员时使用 `->`，例如 `abs->m_Size`。

> [!warning] 更新人数的时机
> 必须在所有信息填写完毕后执行 `m_Size++`。如果提前增加，输入中断或逻辑出错时，通讯录中会多出一条不完整记录。

## 7. 显示联系人

显示前先判断 `m_Size`：等于 `0` 时提示记录为空，否则遍历所有有效联系人。

```cpp
void showPerson(const Addressbooks* abs)
{
    if (abs->m_Size == 0)
    {
        cout << "当前记录为空。" << endl;
    }
    else
    {
        for (int i = 0; i < abs->m_Size; i++)
        {
            cout << "姓名：" << abs->personArray[i].m_Name << "\t";
            cout << "性别："
                 << (abs->personArray[i].m_Sex == 1 ? "男" : "女")
                 << "\t";
            cout << "年龄：" << abs->personArray[i].m_Age << "\t";
            cout << "电话：" << abs->personArray[i].m_Phone << "\t";
            cout << "住址：" << abs->personArray[i].m_Addr << endl;
        }
    }

    system("pause");
    system("cls");
}
```

在菜单的 `case 2` 中调用：

```cpp
case 2:
    showPerson(&abs);
    break;
```

> [!tip] 三目运算符
> `条件 ? 值1 : 值2` 可以把性别编号转换成显示文字。当 `m_Sex == 1` 时显示“男”，否则显示“女”。

> [!note] `const` 的作用
> 显示功能只读取通讯录，不需要修改数据，因此参数可以写成 `const Addressbooks*`。这是在课程代码基础上的安全性补充。

## 8. 删除联系人：检测联系人是否存在

删除、查找和修改都需要先按姓名定位联系人，因此将这段共用逻辑封装为 `isExist()`。

```cpp
int isExist(const Addressbooks* abs, const string& name)
{
    for (int i = 0; i < abs->m_Size; i++)
    {
        if (abs->personArray[i].m_Name == name)
        {
            return i;
        }
    }
    return -1;
}
```

返回值约定：

- 找到联系人：返回其数组下标。
- 未找到联系人：返回 `-1`。

> [!important] 为什么返回下标
> 后续删除、查找和修改都需要知道联系人位于数组的哪个位置。返回下标比只返回 `true` 或 `false` 更实用。

> [!tip] 参数传递
> `const string& name` 避免复制字符串，同时保证函数不会修改传入的姓名。

## 9. 删除联系人：功能实现

固定长度数组不能真正“移除”中间元素。删除下标 `ret` 的联系人时，需要将其后所有元素依次向前覆盖一格，再把有效人数减 `1`。

```cpp
void deletePerson(Addressbooks* abs)
{
    cout << "请输入要删除的联系人姓名：" << endl;
    string name;
    cin >> name;

    int ret = isExist(abs, name);
    if (ret == -1)
    {
        cout << "查无此人。" << endl;
    }
    else
    {
        for (int i = ret; i < abs->m_Size - 1; i++)
        {
            abs->personArray[i] = abs->personArray[i + 1];
        }

        abs->m_Size--;
        cout << "删除成功。" << endl;
    }

    system("pause");
    system("cls");
}
```

在菜单的 `case 3` 中调用：

```cpp
case 3:
    deletePerson(&abs);
    break;
```

> [!important] 删除过程示例
> 原数组为 `[张三, 李四, 王五]`，删除“李四”后，用“王五”覆盖“李四”的位置，随后 `m_Size` 从 `3` 变成 `2`。程序以后只处理前两个有效元素。

> [!warning] 循环边界
> 循环条件应为 `i < m_Size - 1`，因为循环体会读取 `i + 1`。这样最后一次读取的是原数组的最后一个有效元素，不会访问有效范围之外的位置。

## 10. 查找联系人

查找功能先调用 `isExist()` 获取下标。找到后只输出该下标对应的联系人信息。

```cpp
void findPerson(const Addressbooks* abs)
{
    cout << "请输入要查找的联系人姓名：" << endl;
    string name;
    cin >> name;

    int ret = isExist(abs, name);
    if (ret == -1)
    {
        cout << "查无此人。" << endl;
    }
    else
    {
        const Person& person = abs->personArray[ret];
        cout << "姓名：" << person.m_Name << "\t";
        cout << "性别：" << (person.m_Sex == 1 ? "男" : "女") << "\t";
        cout << "年龄：" << person.m_Age << "\t";
        cout << "电话：" << person.m_Phone << "\t";
        cout << "住址：" << person.m_Addr << endl;
    }

    system("pause");
    system("cls");
}
```

在菜单的 `case 4` 中调用：

```cpp
case 4:
    findPerson(&abs);
    break;
```

> [!note] 当前查找规则
> 视频项目按姓名进行精确匹配，并返回第一个同名联系人。如果要支持同名联系人，后续可以改为按电话或唯一编号查找。

## 11. 修改联系人

修改功能与查找功能的前半段相同：先输入姓名并确定下标；找到后直接覆盖该位置的全部字段。

```cpp
void modifyPerson(Addressbooks* abs)
{
    cout << "请输入要修改的联系人姓名：" << endl;
    string oldName;
    cin >> oldName;

    int ret = isExist(abs, oldName);
    if (ret == -1)
    {
        cout << "查无此人。" << endl;
    }
    else
    {
        Person& person = abs->personArray[ret];

        cout << "请输入姓名：" << endl;
        cin >> person.m_Name;

        cout << "请输入性别（1 -- 男，2 -- 女）：" << endl;
        while (true)
        {
            cin >> person.m_Sex;
            if (person.m_Sex == 1 || person.m_Sex == 2)
            {
                break;
            }
            cout << "输入有误，请重新输入：" << endl;
        }

        cout << "请输入年龄：" << endl;
        cin >> person.m_Age;

        cout << "请输入联系电话：" << endl;
        cin >> person.m_Phone;

        cout << "请输入家庭住址：" << endl;
        cin >> person.m_Addr;

        cout << "修改成功。" << endl;
    }

    system("pause");
    system("cls");
}
```

在菜单的 `case 5` 中调用：

```cpp
case 5:
    modifyPerson(&abs);
    break;
```

> [!important] 修改与添加的区别
> 添加联系人写入 `personArray[m_Size]`，完成后需要 `m_Size++`；修改联系人覆盖已有下标 `ret`，联系人总数不变。

> [!tip] 引用让代码更清晰
> `Person& person = abs->personArray[ret];` 为目标联系人创建引用，后面可以直接写 `person.m_Name`，减少重复的长表达式。

## 12. 清空通讯录

清空联系人不必逐个擦除数组，只需把有效人数设为 `0`。

```cpp
void cleanPerson(Addressbooks* abs)
{
    abs->m_Size = 0;
    cout << "通讯录已清空。" << endl;

    system("pause");
    system("cls");
}
```

在菜单的 `case 6` 中调用：

```cpp
case 6:
    cleanPerson(&abs);
    break;
```

> [!important] 逻辑清空
> 将 `m_Size` 设为 `0` 后，原数组中的字节不一定立刻消失，但程序认为有效范围为空，后续显示和查找都不会再访问旧记录。新联系人会从下标 `0` 开始覆盖旧数据。

> [!warning] 数据不会永久保存
> 这个阶段的数据只存在内存中，退出程序后会丢失。若要永久保存，需要继续学习文件操作，将通讯录写入磁盘并在启动时读取。

## 项目结构总结

### 数据流

```text
main 创建并初始化 Addressbooks
              │
              ▼
      while 循环显示菜单
              │
              ▼
       switch 分发用户选择
              │
     ┌────────┼────────┐
     ▼        ▼        ▼
  添加/修改  显示/查找  删除/清空
     │        │        │
     └────────┴────────┘
              │
              ▼
    所有功能操作同一个 abs
```

### 功能函数一览

| 函数 | 作用 | 是否修改通讯录 |
| --- | --- | --- |
| `showMenu()` | 输出菜单 | 否 |
| `addPerson()` | 在末尾添加联系人 | 是 |
| `showPerson()` | 遍历显示全部联系人 | 否 |
| `isExist()` | 按姓名返回联系人下标 | 否 |
| `deletePerson()` | 前移元素并减少人数 | 是 |
| `findPerson()` | 显示指定联系人 | 否 |
| `modifyPerson()` | 覆盖指定联系人的信息 | 是 |
| `cleanPerson()` | 将有效人数设为 `0` | 是 |

> [!summary] 一条主线记住整个项目
> **结构体保存数据 → `m_Size` 管理有效范围 → 菜单循环接收选择 → `switch` 调用功能函数 → 指针让函数操作同一份通讯录。**
