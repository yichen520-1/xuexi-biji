> - 管理员账号文件只有“用户名 密码”，学生和教师文件则是“编号 姓名 密码”，读取字段不能混用。

> - 视频代码将机房编号限制为 `1～3`，更稳妥的写法应根据 `vCom` 中实际机房编号校验。

## 1、机房预约系统需求

### 1.1 系统简介（第 1 集）

学校有若干规格不同的机房，使用高峰期容易出现冲突，因此开发一套预约系统，让学生提交申请、教师进行审核、管理员维护基础数据。

系统涉及三种身份：

| 身份 | 登录凭据 | 主要功能 |
| --- | --- | --- |
| 学生 | 学号、姓名、密码 | 申请预约、查看自身预约、查看所有预约、取消预约 |
| 教师 | 职工号、姓名、密码 | 查看所有预约、审核预约 |
| 管理员 | 姓名、密码 | 添加账号、查看账号、查看机房、清空预约 |

### 1.2 身份功能

#### 学生

1. 申请预约：选择日期、时间段和机房。
2. 查看自身预约：只显示当前学号提交的记录。
3. 查看所有预约：查看系统中的全部预约记录。
4. 取消预约：可取消“审核中”或“预约成功”的本人预约。
5. 注销登录：销毁当前学生对象并返回主菜单。

#### 教师

1. 查看所有预约。
2. 审核预约：对“审核中”的记录选择通过或不通过。
3. 注销登录。

#### 管理员

1. 添加学生或教师账号。
2. 查看全部学生或教师账号。
3. 查看机房编号和最大容量。
4. 清空全部预约记录。
5. 注销登录。

### 1.3 机房信息

课程示例包含三间机房：

| 机房 | 最大容量 |
| --- | ---: |
| 1 号机房 | 20 人 |
| 2 号机房 | 50 人 |
| 3 号机房 | 100 人 |

机房信息保存在 `computer.txt` 中，每行格式为：

```text
1 20
2 50
3 100
```

### 1.4 申请与审核规则

- 学生最多预约未来一周内周一至周五的机房。
- 每天分为上午和下午两个时间段。
- 新提交记录的状态为“审核中”。
- 教师审核通过后变为“预约成功”，审核不通过变为“审核失败”。
- 学生可以取消审核中或预约成功的记录，取消后变为“预约取消”。

> [!important] 状态机
> - `1`：审核中
> - `2`：预约成功
> - `-1`：审核失败
> - `0`：预约取消
>
> 合法流转：`1 -> 2`、`1 -> -1`、`1 -> 0`、`2 -> 0`。

### 1.5 成品展示（第 2 集）

观察成品时应关注的不是菜单外观，而是完整业务链：

```text
管理员创建账号
        ↓
学生登录并申请预约
        ↓
预约记录写入 order.txt，状态为 1
        ↓
教师登录并审核
        ↓
状态更新为 2 或 -1
        ↓
学生查看结果，必要时将记录取消为 0
```

## 3、创建主菜单（第 4 集）

主菜单根据身份提供四个入口：

```cpp
int main()
{
    int select = 0;

    while (true)
    {
        cout << "1. 学生代表" << endl;
        cout << "2. 老师" << endl;
        cout << "3. 管理员" << endl;
        cout << "0. 退出" << endl;
        cout << "请输入您的选择：";
        cin >> select;

        switch (select)
        {
        case 1:
            LoginIn(STUDENT_FILE, 1);
            break;
        case 2:
            LoginIn(TEACHER_FILE, 2);
            break;
        case 3:
            LoginIn(ADMIN_FILE, 3);
            break;
        case 0:
            cout << "欢迎下次使用" << endl;
            system("pause");
            return 0;
        default:
            cout << "输入有误，请重新选择。" << endl;
            system("pause");
            system("cls");
            break;
        }
    }
}
```

`LoginIn()` 接收两个参数：

```cpp
void LoginIn(string fileName, int type);
```

- `fileName`：决定从哪个账号文件中验证。
- `type`：`1` 学生、`2` 教师、`3` 管理员。

> [!important] 接口设计
> 主菜单不关心每种身份如何验证，只把“文件路径 + 身份类型”交给统一登录函数。这样登录流程只需封装一次。

## 4、退出功能（第 5 集）

当用户输入 `0` 时，在 `main()` 中直接执行 `return 0`：

```cpp
case 0:
```

> [!note] `break` 与 `return`
> `break` 只退出 `switch`，外层 `while (true)` 仍会继续；`return 0` 才会结束 `main()` 和整个程序。

## 5、创建身份类

### 5.1 身份抽象基类（第 6 集）

学生、教师和管理员都有姓名、密码和操作菜单，因此提取为抽象基类：

```cpp
// Identity.h
#pragma once
#include <iostream>
#include <string>
using namespace std;

class Identity
{
public:
    virtual void operMenu() = 0;
    virtual ~Identity() = default;

    string m_Name;
    string m_Pwd;
};
```

`operMenu()` 是纯虚函数，`Identity` 不能直接实例化，三个派生类必须各自实现菜单。

> [!important] 多态的作用
> 登录函数只需要维护一个 `Identity* person`。验证成功后让它指向不同派生类对象，再把它传给对应菜单函数，形成统一的身份抽象。

### 5.2 学生类（第 7 集）

学生除姓名和密码外，还需要学号和可预约机房列表：

```cpp
class Student : public Identity
{
public:
    Student();
    Student(int id, string name, string pwd);

    virtual void operMenu();
    void applyOrder();
    void showMyOrder();
    void showAllOrder();
    void cancelOrder();

    int m_Id;
    vector<ComputerRoom> vCom;
};
```

学生有参构造函数初始化账号信息，并从 `computer.txt` 读取机房：

```cpp
Student::Student(int id, string name, string pwd)
{
    m_Id = id;
    m_Name = name;
    m_Pwd = pwd;

    ifstream ifs(COMPUTER_FILE, ios::in);
    ComputerRoom com;
    while (ifs >> com.m_ComId >> com.m_MaxNum)
    {
        vCom.push_back(com);
    }
}
```

### 5.3 教师类（第 8 集）

```cpp
class Teacher : public Identity
{
public:
    Teacher();
    Teacher(int empId, string name, string pwd);

    virtual void operMenu();
    void showAllOrder();
    void validOrder();

    int m_EmpId;

```

教师只负责查看和审核预约，不需要保存机房容器。

### 5.4 管理员类（第 9 集）

```cpp
class Manager : public Identity
{
public:
    Manager();
    Manager(string name, string pwd);

    virtual void operMenu();
    void addPerson();
    void showPerson();
    void showComputer();
    void cleanFile();

    bool checkRepeat(int id, int type);

    vector<Student> vStu;
    vector<Teacher> vTea;
    vector<ComputerRoom> vCom;

```

管理员构造时需要加载学生、教师和机房信息，为查看账号、查重和展示机房做准备。

### 5.5 全局文件（第 10 集）

将所有数据文件名集中写入 `globalFile.h`：

```cpp
#pragma once

#define ADMIN_FILE    "admin.txt"
#define STUDENT_FILE  "student.txt"
#define TEACHER_FILE  "teacher.txt"
#define COMPUTER_FILE "computer.txt"
#define ORDER_FILE    "order.txt"
```

> [!tip] 集中管理的好处
> 文件名发生变化时只需修改一处，也能避免不同源文件中出现拼写不一致。

## 6、登录模块

### 6.1 登录函数接口封装（第 11 集）

统一流程：

1. 创建基类指针 `Identity* person = nullptr`。
2. 按传入文件名打开账号文件。
3. 根据身份类型收集编号、姓名和密码。
4. 遍历文件并比对全部字段。
5. 成功后创建对应派生类对象并进入子菜单。
6. 遍历结束仍未匹配，则提示登录失败。

```cpp
void LoginIn(string fileName, int type)
{
    Identity* person = nullptr;
    ifstream ifs(fileName, ios::in);

    if (!ifs.is_open())
    {
        cout << "文件不存在" << endl;
        return;
    }

    int id = 0;
    string name;
    string pwd;

    if (type == 1)
    {
        cout << "请输入学号：";
        cin >> id;
    }
    else if (type == 2)
    {
        cout << "请输入职工号：";
        cin >> id;
    }

    cout << "请输入用户名：";
    cin >> name;
    cout << "请输入密码：";
    cin >> pwd;

    // 后续根据 type 读取不同格式并验证
}
```

### 6.2 学生身份登录（第 12 集）

学生文件每行格式：


```cpp
int fId;

        studentMenu(person);

}
```

### 6.3 教师身份登录（第 13 集）

教师文件同样是三个字段：

```text

```

```cpp
while (ifs >> fId >> fName >> fPwd)
{
    if (fId == id && fName == name && fPwd == pwd)
    {
        person = new Teacher(id, name, pwd);
```

### 6.4 管理员身份登录（第 14 集）

管理员文件没有编号，每行只有两个字段：

```text
用户名 密码
```

```cpp
string fName;
string fPwd;

while (ifs >> fName >> fPwd)
{
    if (fName == name && fPwd == pwd)
    {
        person = new Manager(name, pwd);
        managerMenu(person);
        return;
    }
}
```

> [!warning] 登录失败的位置
> “登录失败”必须放在文件遍历结束之后。若写进 `while` 的 `else` 中，只要第一条记录不匹配就会立即失败，后面的账号根本没有机会验证。

## 7、管理员模块

### 7.1 管理员子菜单和注销（第 15 集）

管理员菜单包含添加账号、查看账号、查看机房、清空预约和注销：

```cpp
void managerMenu(Identity*& manager)
{
    while (true)
    {
        manager->operMenu();
        Manager* man = (Manager*)manager;

        int select = 0;
        cin >> select;

        switch (select)
        {
        case 1: man->addPerson();    break;
        case 2: man->showPerson();   break;
        case 3: man->showComputer(); break;
        case 4: man->cleanFile();    break;
        default:
            delete manager;
            manager = nullptr;
            cout << "注销成功" << endl;
            system("pause");
            system("cls");
            return;
        }
    }
}
```

> [!note] 指针转换
> `Identity*` 只能调用基类公开的成员。要调用管理员独有的 `addPerson()` 等函数，需要转成 `Manager*`。实际项目中可使用 `dynamic_cast<Manager*>` 做带检查的转换。

### 7.2 添加账号（第 16 集）

添加账号时先选择学生或教师，再以追加方式打开对应文件：

```cpp
string fileName;
int select = 0;
cin >> select;

if (select == 1)
    fileName = STUDENT_FILE;
else if (select == 2)
    fileName = TEACHER_FILE;
else
    return;

ofstream ofs(fileName, ios::out | ios::app);
```

收集编号、姓名和密码并写入：

```cpp
int id;
string name;
string pwd;

cin >> id;
cin >> name;
cin >> pwd;

ofs << id << ' ' << name << ' ' << pwd << endl;
```

`ios::app` 会把新账号添加到文件末尾，不会覆盖已有内容。

### 7.3 获取学生和教师信息（第 17 集）

管理员用两个容器保存账号对象：

```cpp
vector<Student> vStu;
vector<Teacher> vTea;
```

`initVector()` 每次加载前先清空旧数据：

```cpp
void Manager::initVector()
{
    vStu.clear();
    vTea.clear();

    ifstream ifs(STUDENT_FILE, ios::in);
    Student s;
    while (ifs >> s.m_Id >> s.m_Name >> s.m_Pwd)
    {
        vStu.push_back(s);
    }
    ifs.close();

    ifs.open(TEACHER_FILE, ios::in);
    Teacher t;
    while (ifs >> t.m_EmpId >> t.m_Name >> t.m_Pwd)
    {
        vTea.push_back(t);
    }
}
```

> [!important] 为什么先 `clear()`
> 如果不清空，重复调用 `initVector()` 会把同一批文件数据再次追加到容器，导致账号重复显示。

### 7.4 检测重复账号及 Bug 修复（第 18～19 集）

学生学号和教师职工号都应唯一：

```cpp
bool Manager::checkRepeat(int id, int type)
{
    if (type == 1)
    {
        for (const Student& stu : vStu)
            if (stu.m_Id == id)
                return true;
    }
    else if (type == 2)
    {
        for (const Teacher& tea : vTea)
            if (tea.m_EmpId == id)
                return true;
    }

    return false;
}
```

添加时循环输入，直到编号不重复：

```cpp
while (true)
{
    cin >> id;
    if (checkRepeat(id, select))
        cout << "编号重复，请重新输入：";
    else
        break;
}
```

第 19 集修复的关键问题是：**文件已写入新账号，但内存容器没有同步更新**。因此写入完成后必须重新加载：

```cpp
ofs << id << ' ' << name << ' ' << pwd << endl;
ofs.close();

initVector();
```

### 7.5 查看账号（第 20 集）

可以使用普通函数配合 `for_each`：

```cpp
void printStudent(const Student& s)
{
    cout << "学号：" << s.m_Id
         << " 姓名：" << s.m_Name
         << " 密码：" << s.m_Pwd << endl;
}

void printTeacher(const Teacher& t)
{
    cout << "职工号：" << t.m_EmpId
         << " 姓名：" << t.m_Name
```

### 8.3 预约类的容器属性（第 25 集）

一条预约包含六个“字段名 → 字段值”，适合使用：

```cpp
map<string, string>
```

多条预约还需要“记录下标 → 单条预约”的映射，因此使用嵌套容器：

```cpp
map<int, map<string, string>> m_orderData;
```

完整预约类：

```cpp
class OrderFile
{
public:
    OrderFile();
    void updateOrder();

    map<int, map<string, string>> m_orderData;
    int m_Size;
};
```

访问示例：

```cpp
m_orderData[0]["stuName"];
m_orderData[0]["status"];
```

> [!note] 数据结构理解
> 外层 `map` 的键是第几条预约，内层 `map` 的键是字段名。课程使用这种结构练习 STL；实际工程也可以定义 `Order` 结构体，让字段类型更明确。

### 8.4 获取所有预约信息（第 26 集）

构造 `OrderFile` 对象时读取全部记录：

```cpp
OrderFile::OrderFile()
{
    ifstream ifs(ORDER_FILE, ios::in);
    m_Size = 0;

    string date, interval, stuId, stuName, roomId, status;

    while (ifs >> date >> interval >> stuId
               >> stuName >> roomId >> status)
    {
        map<string, string> record;
        // 依次解析六个 token
        m_orderData.insert(make_pair(m_Size, record));
        ++m_Size;
    }
}
```

单个 token 的解析方式：

```cpp
int pos = date.find(':');
if (pos != string::npos)
{
    string key = date.substr(0, pos);
    string value = date.substr(pos + 1);
    record.insert(make_pair(key, value));
}
```

六个字段使用同样方式解析，最终得到：

```text
record["date"]
record["interval"]
record["stuId"]
record["stuName"]
record["roomId"]
record["status"]
```

> [!warning] `substr` 起点
> 键在冒号前，因此是 `substr(0, pos)`；值从冒号后一位开始，因此是 `substr(pos + 1)`。

### 8.5 更新预约记录（第 27 集）

审核或取消只修改了 `m_orderData` 中的值，还要把整个容器重新写回文件：

```cpp
void OrderFile::updateOrder()
{
    if (m_Size == 0)
        return;

    ofstream ofs(ORDER_FILE, ios::out | ios::trunc);

    for (int i = 0; i < m_Size; ++i)
    {
        ofs << "date:"     << m_orderData[i]["date"]
            << " interval:" << m_orderData[i]["interval"]
            << " stuId:"    << m_orderData[i]["stuId"]
            << " stuName:"  << m_orderData[i]["stuName"]
            << " roomId:"   << m_orderData[i]["roomId"]
            << " status:"   << m_orderData[i]["status"]
            << endl;
    }
}
```

这里必须使用 `ios::trunc`，因为需要用内存中的最新状态重建整个文件。

### 8.8 取消预约（第 30 集）

只有同时满足以下条件的记录才可取消：

1. 记录属于当前学生。
2. 状态为审核中 `1` 或预约成功 `2`。

筛选时用 `vector<int>` 保存真实记录下标：

```cpp
vector<int> indexes;
int displayIndex = 1;

for (int i = 0; i < file.m_Size; ++i)
{
    bool isMine = m_Id == atoi(file.m_orderData[i]["stuId"].c_str());
    string status = file.m_orderData[i]["status"];
    bool canCancel = status == "1" || status == "2";

    if (isMine && canCancel)
    {
        indexes.push_back(i);
        cout << displayIndex++ << "、";
        // 输出可取消记录
    }
}
```

用户输入的是显示序号，修改时要映射回真实下标：

```cpp
int select = 0;
cin >> select;

if (select > 0 && select <= static_cast<int>(indexes.size()))
{
    int realIndex = indexes[select - 1];
    file.m_orderData[realIndex]["status"] = "0";
    file.updateOrder();
}
```

> [!important] 本集核心
> 菜单中的第 `1` 条可能是文件中的第 `5` 条记录，所以不能直接用 `select - 1` 修改 `m_orderData`。`indexes` 专门保存“显示序号 → 文件记录下标”的对应关系。
