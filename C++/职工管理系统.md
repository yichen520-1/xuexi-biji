# 职工管理系统

> [!info] 课程范围
> 对应视频 [BV1et411b73Z](https://www.bilibili.com/video/BV1et411b73Z/?p=147) 的 P147-P166，即“职工管理系统”第 1-20 集。

本项目使用 C++ 的**封装、继承、多态、动态内存和文件读写**，完成一个可持久化保存数据的职工管理系统。

## 第1集 管理系统需求

职工分为三类：

| 部门编号 | 职工类型 | 岗位职责 |
| --- | --- | --- |
| 1 | 普通员工 | 完成经理交给的任务 |
| 2 | 经理 | 完成老板交给的任务，并向员工下发任务 |
| 3 | 老板 | 管理公司所有事务 |

每名职工需要保存：**职工编号、姓名、部门编号**。系统需要实现：

1. 退出管理程序
2. 增加职工
3. 显示职工
4. 删除职工
5. 修改职工
6. 查找职工
7. 按编号排序
8. 清空所有数据

> [!important] 本集重点
> 这是一个基于多态的项目：管理类只保存 `Worker*`，实际对象可以是 `Employee`、`Manager` 或 `Boss`。

## 第6集 创建职工抽象类和普通员工类

### 6.1 职工抽象基类

```cpp
// worker.h
#pragma once
#include <iostream>
#include <string>
using namespace std;

class Worker
{
public:
    virtual void showInfo() = 0;
    virtual string getDeptName() = 0;
    virtual ~Worker() = default;

    int m_Id;
    string m_Name;
    int m_DeptId;
};
```

### 6.2 普通员工类

```cpp
// employee.h
#pragma once
#include "worker.h"

class Employee : public Worker
{
public:
    Employee(int id, string name, int deptId);
    void showInfo() override;
    string getDeptName() override;
};
```

```cpp
// employee.cpp
#include "employee.h"

Employee::Employee(int id, string name, int deptId)
{
    m_Id = id;
    m_Name = name;
    m_DeptId = deptId;
}

void Employee::showInfo()
{
    cout << "职工编号：" << m_Id
         << "\t职工姓名：" << m_Name
         << "\t岗位：" << getDeptName()
         << "\t岗位职责：完成经理交给的任务" << endl;
}

string Employee::getDeptName()
{
    return "员工";
}
```

> [!important] 本集重点
> 含有纯虚函数的类是抽象类，不能直接创建对象。派生类必须重写纯虚函数，`override` 能帮助编译器检查重写是否正确。

## 第8集 添加职工

### 8.1 管理类新增属性

```cpp
int m_EmpNum;          // 当前职工人数
Worker** m_EmpArray;   // 指向“职工指针数组”的指针
bool m_FileIsEmpty;    // 文件是否为空
```

### 8.2 批量添加

```cpp
void WorkerManager::Add_Emp()
{
    cout << "请输入添加职工数量：";
    int addNum = 0;
    cin >> addNum;

    if (addNum <= 0)
    {
        cout << "输入有误" << endl;
        return;
    }

    int newSize = m_EmpNum + addNum;
    Worker** newSpace = new Worker*[newSize];

    for (int i = 0; i < m_EmpNum; ++i)
        newSpace[i] = m_EmpArray[i];

    for (int i = 0; i < addNum; ++i)
    {
        int id = 0;
        int deptId = 0;
        string name;

        cout << "请输入第 " << i + 1 << " 名职工编号：";
        cin >> id;
        cout << "请输入姓名：";
        cin >> name;
        cout << "请选择岗位（1员工 2经理 3老板）：";
        cin >> deptId;

        Worker* worker = nullptr;
        if (deptId == 1)
            worker = new Employee(id, name, deptId);
        else if (deptId == 2)
            worker = new Manager(id, name, deptId);
        else if (deptId == 3)
            worker = new Boss(id, name, deptId);
        else
        {
            cout << "岗位编号无效，默认创建普通员工" << endl;
            deptId = 1;
            worker = new Employee(id, name, deptId);
        }

        newSpace[m_EmpNum + i] = worker;
    }

    delete[] m_EmpArray;       // 只释放旧的指针数组
    m_EmpArray = newSpace;
    m_EmpNum = newSize;
    m_FileIsEmpty = false;
    Save();
}
```

> [!warning] 易错点
> 扩容时不能删除旧数组中指向的职工对象，因为新数组仍要使用这些对象。此处只执行 `delete[] m_EmpArray`。

## 第12集 读文件：统计职工人数

```cpp
int WorkerManager::get_EmpNum()
{
    ifstream ifs(FILENAME, ios::in);
    int id = 0;
    int deptId = 0;
    string name;
    int count = 0;

    while (ifs >> id >> name >> deptId)
        ++count;

    return count;
}
```

在构造函数中记录人数：

```cpp
m_EmpNum = get_EmpNum();
```

> [!important] 本集重点
> `while (ifs >> id >> name >> deptId)` 以“一条完整记录读取成功”为循环条件，比单独判断 `eof()` 更可靠。

## 第13集 读文件：初始化职工数组

```cpp
void WorkerManager::init_Emp()
{
    ifstream ifs(FILENAME, ios::in);
    int id = 0;
    int deptId = 0;
    string name;
    int index = 0;

    while (ifs >> id >> name >> deptId)
    {
        Worker* worker = nullptr;

        if (deptId == 1)
            worker = new Employee(id, name, deptId);
        else if (deptId == 2)
            worker = new Manager(id, name, deptId);
        else
            worker = new Boss(id, name, deptId);

        m_EmpArray[index++] = worker;
    }
}
```

构造函数中完成初始化：

```cpp
m_EmpNum = get_EmpNum();
m_EmpArray = new Worker*[m_EmpNum];
init_Emp();
m_FileIsEmpty = false;
```

析构函数释放内存：

```cpp
WorkerManager::~WorkerManager()
{
    for (int i = 0; i < m_EmpNum; ++i)
        delete m_EmpArray[i];

    delete[] m_EmpArray;
    m_EmpArray = nullptr;
}
```

## 第15集 删除职工：判断职工是否存在

多个功能都要先定位职工，因此将查询下标封装为通用函数：

```cpp
int WorkerManager::IsExist(int id)
{
    for (int i = 0; i < m_EmpNum; ++i)
    {
        if (m_EmpArray[i]->m_Id == id)
            return i;
    }
    return -1;
}
```

> [!tip] 返回下标而不是 `bool`
> 删除和修改不仅要知道职工是否存在，还需要知道其在数组中的位置。未找到时统一返回 `-1`。

## 第16集 删除职工：功能实现

```cpp
void WorkerManager::Del_Emp()
{
    if (m_FileIsEmpty)
    {
        cout << "文件不存在或记录为空" << endl;
        return;
    }

    int id = 0;
    cout << "请输入要删除的职工编号：";
    cin >> id;

    int index = IsExist(id);
    if (index == -1)
    {
        cout << "未找到该职工" << endl;
        return;
    }

    delete m_EmpArray[index];

    for (int i = index; i < m_EmpNum - 1; ++i)
        m_EmpArray[i] = m_EmpArray[i + 1];

    --m_EmpNum;
    if (m_EmpNum == 0)
        m_FileIsEmpty = true;

    Save();
    cout << "删除成功" << endl;
}
```

> [!warning] 易错点
> 先 `delete` 被删除的对象，再将后续元素向前移动。数组容量虽未缩小，但有效元素数量由 `m_EmpNum` 控制。

void WorkerManager::Mod_Emp()

> 多态对象的真实类型可能改变，因此最直接的做法是释放旧对象，再根据新岗位创建新的派生类对象。

## 第18集 查找职工

支持按编号或姓名查找：

```cpp
void WorkerManager::Find_Emp()
{
    if (m_FileIsEmpty)
    {
        cout << "文件不存在或记录为空" << endl;
        return;
    }

    cout << "1.按职工编号查找" << endl;
    cout << "2.按职工姓名查找" << endl;

    int choice = 0;
    cin >> choice;

    if (choice == 1)
    {
        int id = 0;
        cin >> id;
        int index = IsExist(id);

        if (index != -1)
            m_EmpArray[index]->showInfo();
        else
            cout << "查无此人" << endl;
    }
    else if (choice == 2)
    {
        string name;
        cin >> name;
        bool found = false;

        for (int i = 0; i < m_EmpNum; ++i)
        {
            if (m_EmpArray[i]->m_Name == name)
            {
                m_EmpArray[i]->showInfo();
                found = true;
            }
        }

        if (!found)
            cout << "查无此人" << endl;
    }
}
```

> [!note] 编号与姓名的区别
> 编号通常唯一，找到后即可返回；姓名可能重复，因此按姓名查找时应继续遍历并显示全部匹配项。

## 第19集 按职工编号排序

课程使用选择排序，用户可选择升序或降序：

```cpp
void WorkerManager::Sort_Emp()
{
    if (m_FileIsEmpty)
    {
        cout << "文件不存在或记录为空" << endl;
        return;
    }

    cout << "1.按编号升序" << endl;
    cout << "2.按编号降序" << endl;
    int choice = 0;
    cin >> choice;

    for (int i = 0; i < m_EmpNum - 1; ++i)
    {
        int selected = i;

        for (int j = i + 1; j < m_EmpNum; ++j)
        {
            bool shouldSelect = choice == 1
                ? m_EmpArray[selected]->m_Id > m_EmpArray[j]->m_Id
                : m_EmpArray[selected]->m_Id < m_EmpArray[j]->m_Id;

            if (shouldSelect)
                selected = j;
        }

        if (selected != i)
        {
            Worker* temp = m_EmpArray[i];
            m_EmpArray[i] = m_EmpArray[selected];
            m_EmpArray[selected] = temp;
        }
    }

    Save();
    Show_Emp();
}
```

> [!important] 本集重点
> 交换的是 `Worker*` 指针，不需要复制整个职工对象。排序后必须保存，否则下次启动时文件仍是旧顺序。

## 第20集 清空文件

```cpp
void WorkerManager::Clean_File()
{
    cout << "确认清空？" << endl;
    cout << "1.确认" << endl;
    cout << "2.返回" << endl;

    int choice = 0;
    cin >> choice;

    if (choice != 1)
        return;

    ofstream ofs(FILENAME, ios::trunc);
    ofs.close();

    for (int i = 0; i < m_EmpNum; ++i)
        delete m_EmpArray[i];

    delete[] m_EmpArray;
    m_EmpArray = nullptr;
    m_EmpNum = 0;
    m_FileIsEmpty = true;

    cout << "清空成功" << endl;
}
```

> [!warning] 清空操作的两个层面
> 既要用 `ios::trunc` 清空磁盘文件，也要释放内存中的所有职工对象和指针数组。只做其中一步会造成数据不同步或内存泄漏。

## 项目总复习

### 核心知识点

- **多态**：`Worker*` 统一管理三种职工对象。
- **动态内存**：职工对象和指针数组均创建在堆区，必须成对释放。
- **文件持久化**：启动时读文件，数据变化后写文件。
- **功能封装**：每项菜单功能对应 `WorkerManager` 的一个成员函数。
- **状态一致性**：`m_EmpNum`、`m_EmpArray`、`m_FileIsEmpty` 和文件内容要始终同步。

### 推荐完成顺序

```text
需求分析
  -> 搭建类和菜单
  -> 建立职工继承体系
  -> 添加职工并保存
  -> 启动时读取文件
  -> 显示 / 删除 / 修改 / 查找
  -> 排序 / 清空
  -> 检查内存释放和文件同步
```

### 高频易错点

1. 抽象基类缺少虚析构函数，可能导致通过父类指针删除子类对象时析构不完整。
2. 动态数组扩容时误删数组中的职工对象。
3. 删除或修改后忘记调用 `Save()`。
4. 只判断文件是否存在，没有判断文件是否为空。
5. 清空文件后没有重置内存状态。
6. 按姓名查找时找到一人就退出，遗漏同名职工。
