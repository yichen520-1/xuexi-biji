### 1. 变量与声明方式（第 07、11、13 集）

**是什么**：JS 声明变量用三个关键字——`let`（块级、可改，默认用它）、`const`（块级、绑定不可改）、`var`（老写法，只作对比）。

**对照 C++17**：`let x = 1` 可类比 C++ 的局部变量初始化；`const` 约束对象或绑定，但语义不完全相同。

**差异（重点）**：

- **JS 没有类型声明。** 写的是 `let x = 1`，不是 `int x = 1`；而且变量可以**中途换类型** —— `x = 'hello'` 完全合法。C++ 是静态类型语言，这一步编译就过不去。
- **var 与 let 作用域不同**：var 通常为函数作用域，let/const 为块作用域。C++ 局部变量通常属块作用域，也存在命名空间、类等作用域。
- **`const` 锁的是"绑定"，不是"内容"。** `const obj = {}` 之后 `obj.a = 1` 完全合法 —— 不许改的是"obj 这个名字指向谁"，不是它指向的东西。这一点与 C++ 的 const 对象约束有相似处，但不能等同，但很多人会误以为 const 对象是冻结的。

### 2. 数据类型（第 14、15、16、17 集）

**是什么**：JS 的基础类型只有 `Number`、`String`、`Boolean`、`null`、`undefined`（外加对象/数组/函数）。

**对照 C++17**：`Number` ≈ 数字；`String` ≈ `string`；`Boolean` ≈ `bool`。

**差异（重点，全是坑）**：

- **本课使用 Number**：统一表示常见整数和浮点数；JS 另有 BigInt，不能与 Number 直接混算。Number 的三个常见现象：
  - `0.1 + 0.2 !== 0.3`：JS Number 与 C++ 常见二进制 double 都有浮点误差；C++17 标准库也没有内建十进制定点类型。
  - Number 的 `1 / 0` 得 Infinity；C++ 整数除零为未定义行为，不保证抛异常；JS BigInt 除零会抛 RangeError。
  - 有个专属值 `NaN`（Not a Number），而且 `NaN === NaN` 是 `false`。
- **字符串单双引号等价**，`'a'` 和 `"a"` 是同一个东西（C++ 单引号表示 char）。
- **模板字符串**：`` `文本${变量}` `` C++17 没有同语法的模板字符串；通常使用 `std::ostringstream` 拼接，或在 C++20 使用格式化库。
- **JS 有两个"空"**：`null`（人为置空）和 `undefined`（没赋值/不存在）。C++ 没有 JS 的 `undefined`；`nullptr` 表示空指针，`std::optional<T>` 可表达“有值/无值”。
- **`typeof` 只能粗略对照 C++ 的类型查询（如 `typeid`），但粗糙且有历史坑**：`typeof null === 'object'`（这是个一直没修的 bug）。

### 3. 类型转换（第 18 集）

**是什么**：分隐式转换（JS 自动做）和显式转换（你手动转）。

**对照 C++17**：`Number()` / `parseInt()` 可对照 `std::stoi`、`std::from_chars` 等转换接口。

**差异（重点，万坑之源）**：

- **运算符决定转换方向**：`+` 偏字符串（做拼接），其余运算符偏数字（做运算）。
  - `'1' + 1` → `'11'`
  - `'3' - 1` → `2`
  - 同样是字符串配数字，结果一个是拼接一个是运算 —— **这是 JS 最经典的坑**。
- **转换失败策略不同**：JS Number/parseInt 的常见非法文本结果为 NaN；C++ std::stoi 可抛 invalid_argument/out_of_range，std::from_chars 返回错误码。

### 4. 运算符与真假值（第 22、23、61、62 集）

**是什么**：赋值 / 自增 / 比较 / 逻辑 / 三元，和 C++ 大体同名同义。

**差异（重点）**：

- **比较要重新理解**：JS == 可转类型，=== 不做该转换。C++ 内建 == 也能比较可隐式转换的算术类型，不是类型不同就必然编译失败。
- **逻辑运算符返回的不是布尔值**。C++ 的 `&&` `||` 只产出 bool；JS 的**短路返回的是"原值"**：`0 || 'x'` 得 `'x'`，`'a' && 'b'` 得 `'b'`。常用来取默认值和做短路执行 —— **这个直觉千万别从 C++ 迁移过来**。
- **JS 假值**：false、+0、-0、0n、空字符串、null、undefined、NaN（浏览器另有 document.all 历史特例）；[] 与 {} 为真。C++ 条件也允许数值、指针等转 bool，规则不同。
- **`switch` 内部用严格比较（`===`）**，且 `case` 不写 `break` 会穿透（这点和 C++ 一样）。

### 5. 数组（第 12、36、41、43、44、46 集）

**是什么**：JS 数组是**万能动态容器**——长度可变、类型可混。

**对照 C++17**：**更接近 `std::vector` 的动态序列，但 JS 可混合类型；C++ `std::vector<T>` 通常要求元素同质**。

**差异（重点）**：

- `[1, 'a', true, {}]` 合法，一个数组里什么都能塞，长度随时变。
- **`arr.length` 是属性，不是方法**（可类比 `std::vector::size()`，但 JS 使用属性）。
- **数组越界规则不同**：JS arr[99]=1 可扩长并留下空槽；C++ 数组和 vector 的 [] 越界为未定义行为，vector::at 越界抛 out_of_range，不自动扩容。
- 增删方法：`push` / `unshift` 可类比 `std::vector::push_back` / `insert`；`pop` / `shift` / `splice` 对标 `std::vector::erase`。其中 **`splice` 最灵活也最容易用错**（增删改一把抓）。
- C++ 侧你会顺手用 `std::max_element` 或手写循环，这里**故意手写循环** —— 因为数组高阶方法要到进阶篇才解锁。

### 6. 函数与作用域（第 49-62 集）

**是什么**：`function` 声明函数；函数是一等公民，可以赋值给变量、当参数传。

**对照 C++17**：函数 ≈ 方法；**回调函数 ≈ 函数指针、Lambda、函数对象或 `std::function`**（概念相近，但 C++ 语法和类型系统不同）；函数表达式可类比函数对象变量或 Lambda 对象。

**差异（重点）**：

- **写法少了返回类型和参数类型**，逻辑与 C++ 方法一致。
- **不校验参数个数**：传少了不报错，缺的参数是 `undefined`（C++ 直接编译不过）。
- **不写 `return` 时函数返回 `undefined`**。C++ 的 `void` 是"不产生值"，不是"产生一个空值" —— 这两个概念在 JS 里被合并了。
- **顶层绑定不都在 window**：经典脚本顶层 var 通常形成全局对象属性，let/const 不会；模块有独立作用域。未声明赋值在严格模式会抛错。
- **变量的访问原则 = 作用域链**（第 57 集给初步模型，第 152 集深讲）：从内往外一层层找。
- **匿名函数之函数表达式**：`let fn = function () {}` —— 这就是"函数是一等公民"的落地。⚠️ 本课程讲的是 `function () {}` 写法，**箭头函数留到第 157 集，现在不用**。
- **IIFE**：JS 可立即调用函数表达式创建局部作用域；C++17 也可立即调用 Lambda `[] { /* ... */ }();`，捕获和生命周期规则不同。

---

### 7. 对象与内置对象（第 64-68、70、71 集）

**是什么**：对象字面量 `{ key: value }`；对象里存函数就是方法；内置对象先学 `Math`。

**对照 C++17**：对象字面量可类比 `struct/class` 的聚合数据，动态键访问可类比 `std::unordered_map` —— 因为它能动态加字段。`Math` 可类比 `<cmath>` 中的数学函数，但标准 C++ 没有同名的 Math 静态类。

**差异（重点）**：

- **运行时可动态增删属性**：`obj.newKey = 1`、`delete obj.key` 都合法。C++ 对象的成员编译期就固定了，**这是两种类型系统的根本差别**。
- **查属性有两种写法**：`obj.key` 与 `obj['key']`，后者能接**动态键名**（对标字典索引器）。
- **`for...in` 遍历对象** ≈ C++ 遍历 `std::unordered_map` 或类成员（需显式设计）取属性。
- **Math.random()** 返回 [0,1) 内 Number；C++17 通常将随机数引擎与 std::uniform_real_distribution 等分布组合，再用函数调用运算符取样。

### 8. 简单类型与引用类型（第 76 集）

**是什么**：变量到底存"值"还是存"地址"。

**对照 C++17**：值类型 / 引用类型 —— 只能作部分类比：C++ 的拷贝、引用、指针和 RAII 需要分别理解，不能简单等同。

**差异（重点）**：

- **JS 里只有「对象 / 数组 / 函数」是引用**，其余（**包括字符串**）都是值类型。
- ⚠️ 反直觉的一点：**C++ 的 `std::string` 是可拷贝的对象值语义**，**JS 的字符串是货真价实的值类型**。
- 这一集是第 187-190 集**深浅拷贝**的地基，现在先把"引用共享"这件事摆正。

<span style="background-color:rgb(255, 249, 227)">二：格式</span>

**变量声明：**

```js
let 名 = 值;        // 块级，可改（默认用它）
const 名 = 值;      // 块级，绑定不可改
var 名 = 值;        // 函数作用域 + 提升（老写法，只作对比）
```

**数据类型字面量：**

```js
Number    1 / 3.14 / Infinity / NaN
String    'abc' / "abc" / `abc`
Boolean   true / false
空        null / undefined
数组      [1, 'a', true]
对象      { key: value }
```

**模板字符串：**

```js
`文本${变量}文本`        // C++17 可用 std::ostringstream 拼接，无同语法插值
```

**运算符：**

```js
===  !==                 // 严格，推荐
==   !=                  // 宽松，会转类型，少用
+ - * / %                // / 不会报错，除以 0 得 Infinity
&& || !                  // 短路返回原值，不是 bool
```

**分支：**

```js
if (条件) { } else { }
switch (值) { case 值1: …; break; default: … }   // 内部用 === 比较
```

**循环：**

```js
for (let i = 0; i < n; i++) { }
while (条件) { }
for (let i = 0; i < arr.length; i++) { }   // 遍历数组
for (let k in obj) { }                     // 遍历对象（键）
break; continue;                           // 同 C++
```

**数组常用：**

```js
arr.length                     // 属性，不是方法
arr.push(x)   arr.unshift(x)   // 尾 / 头 添加
arr.pop()     arr.shift()      // 尾 / 头 删除
arr.splice(起点, 个数, 新元素…)  // 万能增删改
```

**函数：**

```js
function 名(参数) { return 值; }      // 声明式
let 名 = function (参数) { };         // 函数表达式（匿名函数）
(function () { })();                  // IIFE，立即执行
// 参数未传 → undefined；不写 return → 返回 undefined
```

**对象：**

```js
let o = { key: 值, key2: 值2 };
o.key        o['key']        // 读（方括号可接动态键名）
o.key = 值                   // 增 / 改
delete o.key                 // 删
o.key = function () { };     // 存函数 = 方法
```

**内置对象：**

```js
Math.max(x, y)  Math.min(x, y)  Math.floor(x)  Math.ceil(x)
Math.round(x)   Math.abs(x)     Math.random()   // 0 ~ 1 的小数
```

### 类型与转换的坑（第 07、14、17、18 集）

```js
let a = 1;              // 不需要写类型
a = 'hello';            // 中途换类型，完全合法（C++ 编译期通常拒绝）
console.log(typeof a);        // string
console.log(typeof null);     // object  ← 历史坑

console.log(0.1 + 0.2);       // 0.30000000000000004
console.log(1 / 0);           // Infinity
console.log('1' + 1);         // '11'  ← + 偏字符串，做拼接
console.log('3' - 1);         // 2     ← 其他运算符偏数字，做运算
console.log(Number('abc'));   // NaN   ← 不抛异常
console.log(parseInt('12px'));// 12
```

**你要观察**：同样是字符串配数字，`-` 出数字、`+` 出字符串；转换失败**不报错**，只给 `NaN`。

### 比较与真假值（第 22、61、62 集）

```js
console.log('1' == 1);        // true   ← 宽松，偷偷转类型
console.log('1' === 1);       // false  ← 严格，永远用它

console.log(Boolean([]));     // true   ← 空数组也是真
console.log(Boolean(0));      // false
console.log(Boolean(''));     // false

let n = 0;
console.log(n || 10);         // 10     ← 短路返回"原值"，常用来取默认值
console.log('a' && 'b');      // 'b'
```

### 数组：动态容器（第 12、43、44、46 集）

```js
let arr = [1, 'a', true];     // 类型可混、长度可变
arr[99] = 1;                  // 不报错！直接撑到 100 长，中间全是 undefined
console.log(arr.length);      // 100

arr.push('尾巴');             // 尾部加（对标 std::vector::push_back）
arr.unshift('头');            // 头部加（对标 std::vector::insert）
arr.pop();                    // 删尾（对标 std::vector::pop_back）
arr.shift();                  // 删头（对标 std::vector::erase）
```

### 函数：一等公民（第 49、50、53、58、59 集）

```js
function sum(a, b) {
    return a + b;
}
console.log(sum(1, 2));       // 3
console.log(sum(1));          // NaN —— 参数少了不报错，b 是 undefined

function log(msg) {
    console.log(msg);
}
log('hi');                    // 打印 hi
console.log(log('hi2'));      // 先打印 hi2，再打印 undefined（没写 return）

let fn = function (x) { return x * 2; };   // 函数表达式
console.log(fn(3));           // 6

(function () {                // IIFE：造一个用完就走的私有作用域
    let secret = '只活在这一刻';
    console.log(secret);
})();
```

### 对象：可动态增删（第 64、65、66、67、68 集）

```js
let stu = { name: '小王', age: 18 };   // 对象字面量
stu.score = 90;               // 运行时动态加属性（标准 C++ 的固定类型对象通常不能这样动态增删）
delete stu.age;               // 动态删属性

console.log(stu.name);        // 小王
let key = 'score';
console.log(stu[key]);        // 90 —— 方括号能接动态键名

stu.say = function () {       // 对象里存函数 = 方法
    console.log('我是' + stu.name);   // 这里先用 stu.name；this 第 67 集埋线、第 102 集正式讲
};
stu.say();

for (let k in stu) {          // 遍历对象
    console.log(k, stu[k]);
}
```

### 内置对象 Math（第 70、71 集）

```js
console.log(Math.max(1, 5, 3));   // 5
console.log(Math.floor(3.9));     // 3
console.log(Math.random());       // 0 ~ 1 的小数（标准 C++ 通常使用随机数引擎与分布）
let n = Math.floor(Math.random() * 10) + 1;   // 1~10 的整数
```

### 值类型 / 引用类型（第 76 集）

```js
let a = 1;
let b = a;
b = 99;
console.log(a);          // 1  —— 值类型，各存各的

let o1 = { x: 1 };
let o2 = o1;             // 只是把"地址"复制了一份
o2.x = 99;
console.log(o1.x);       // 99 —— 引用类型，改的是同一个对象

let s1 = 'abc';
let s2 = s1;
s2 = 'xyz';
console.log(s1);         // abc；C++ std::string 也是可拷贝值对象，但内容可修改
```

### 5. 最容易被 C++ 直觉带偏的 8 个坑（优先级从高到低）

| # | 坑                        | 正确认知                                      |
| - | ------------------------ | ----------------------------------------- |
| 1 | `+` 以为一定是加法              | `+` 偏字符串拼接，`-` 才偏数字运算                     |
| 2 | 以为 `==` 和 C++ 一样          | JS 用 `===`；`==` 会转类型                      |
| 3 | 以为 `&&` `\|``\|` 返回 bool | 短路返回**原值**，常用来取默认值                        |
| 4 | 以为只有 `null` 一个空          | 还有 `undefined`；`typeof null === 'object'` |
| 5 | 以为数组越界会报错                | `arr[99] = 1` 直接把数组撑长                     |
| 6 | 以为类型不匹配会报错               | 变量可换类型、参数可少传、转换失败给 `NaN`                  |
| 7 | 以为 `const` 对象不可改         | 锁的是**绑定**，不是内容                            |
| 8 | 以为字符串是引用类型               | JS 里字符串是**值类型**（只有对象/数组/函数是引用）            |
