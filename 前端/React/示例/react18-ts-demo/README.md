# React18 + TS 可运行任务板

环境：本示例要求 Node 24+（本轮为 24.22.0），测试直接加载 TS 源文件。依赖版本固定见 package.json，npm ci 按锁文件安装，不表示都是最新或适合永久不升级。

```sh
npm ci
npm run check
npm test
npm run build
npm run dev
```

打开终端显示的本机地址。演示不需要课程后台、账号或 token。支持添加、完成、删除、筛选、页面导航与共享统计。导航保留内存状态，刷新后恢复初始数据，不默认持久化。

## 验收步骤

1. 添加两个同名任务，确认身份独立。
2. 完成其中一条，筛选已完成，确认统计同步。
3. 切统计页面，再返回，确认源状态仍在。
4. 删除另一条，确认数量正确。
5. 刷新，确认回到初始记录。

生产构建输出 dist，不提交 Git。preview 用于本机预览，不作为默认生产服务器。使用 hash 路由便于静态练习；迁移 history 模式时另配服务器回退。

自动测试验证数据更新与部分结构，不等于已替你在所有浏览器完成键盘、焦点和部署验收。

src/lesson-* 文件是笔记代码的独立类型检查副本，不默认导入应用运行；其中的示意 API 路径不表示本地存在服务器。
