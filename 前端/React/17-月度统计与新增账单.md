# React：月度统计、分组与新增账单

> **版本口径**：按指定 React18 课程讲解，示例固定 React 18.3.1、Router 6；与 React19 的差异单独说明。
> **来源边界**：已核验课程分集标题；以下原理、示例与练习为结合官方文档自主编写，不是视频逐字稿。

---

<span style="background-color:rgb(255, 249, 227)">一：概念</span>

月度页面由“源账单＋当前月份＋展开状态”推导。按月过滤、按日分组、统计收支都是纯计算，通常直接在渲染或选择器中完成，不用多个 Effect 连锁同步。

---

<span style="background-color:rgb(255, 249, 227)">二：写法与执行过程</span>

```ts
interface Bill { id: string; date: string; amountCents: number; type: 'income' | 'expense' }
export function groupMonth(bills: readonly Bill[], month: string): Map<string, Bill[]> {
  const groups = new Map<string, Bill[]>();
  for (const bill of bills) {
    if (!bill.date.startsWith(`${month}-`)) continue;
    const day = groups.get(bill.date);
    if (day) day.push(bill);
    else groups.set(bill.date, [bill]);
  }
  return groups;
}
```

这里新建 Map 和分组数组，未修改 bills 的源数组。展示顺序仍需明确排序，不能依赖接口或对象键“刚好按日期排列”。Map 在此是计算中间结果，不建议不加设计就塞进要求可序列化的 Redux state。

**新增链路**：表单收集 → 严格校验金额和日期 → 转为统一模型 → 发起创建请求 → 成功后更新源账单或失效重取 → 路由返回。若采用乐观更新，失败时要有回滚和提示。

---

<span style="background-color:rgb(255, 249, 227)">三：对照与易错点</span>

- 当前月份是日历月份，不靠固定 30 天毫秒数计算。
- 日账单展开是 UI 状态，不属于永久账单字段。
- 收入/支出切换会影响可选分类时，要决定如何处理已选但不再合法的分类。
- 金额为零是否允许是业务规则，必须在表单与最终写入口保持一致。

---

<span style="background-color:rgb(255, 249, 227)">四：动手练习</span>

只删除最后一条账单时，统计仍显示旧总数，最先查哪里？

> [!success]- 参考答案
> 检查是否保存了一份额外统计状态或漏依赖。让统计从当前账单派生，空集合自然得到零。
