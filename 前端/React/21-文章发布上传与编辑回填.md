> **版本口径**：按指定 React18 课程讲解，示例固定 React 18.3.1、Router 6；与 React19 的差异单独说明。
> **来源边界**：已核验课程分集标题；以下原理、示例与练习为结合官方文档自主编写，不是视频逐字稿。

<span style="background-color:rgb(255, 249, 227)">一：概念</span>

新增与编辑可以复用表单，但“默认值”“请求中”“已加载的记录”“用户正在改的草稿”是不同阶段。编辑页根据 id 请求详情后回填，不能让迟到响应覆盖用户已经输入的新草稿。封面类型与图片数量应是一套业务规则，而非几处互相独立的判断。

<span style="background-color:rgb(255, 249, 227)">二：写法与执行过程</span>

```ts
type Cover = { type: 'none' } | { type: 'single'; image: string }
  | { type: 'triple'; images: readonly [string, string, string] };
interface ArticleDraft { title: string; channelId: string; content: string; cover: Cover }
export function validateDraft(draft: ArticleDraft): string[] {
  const errors: string[] = [];
  if (!draft.title.trim()) errors.push('标题不能为空');
  if (!draft.channelId) errors.push('请选择频道');
  if (!draft.content.trim()) errors.push('内容不能为空');
  return errors;
}
export async function uploadImage(file: File, signal?: AbortSignal): Promise<unknown> {
  const body = new FormData();
  body.append('file', file);
  const response = await fetch('/api/images', { method: 'POST', body, signal });
  if (!response.ok) throw new Error(`上传失败：${response.status}`);
  return response.json();
}
```

FormData 交给浏览器生成 multipart boundary，不手工写一个不完整的 Content-Type。返回值还要按真实接口验证，教学代码不编造服务字段。

<span style="background-color:rgb(255, 249, 227)">三：对照与易错点</span>

- 文件扩展名与浏览器 MIME 只能帮助交互，服务器仍需验证文件内容、大小与权限。
- 富文本非空不能只用字符串 trim，`<p><br></p>` 等可能视觉为空；应按编辑器数据模型验证。
- 上传成功的 URL、界面上传列表对象与后端提交结构是不同模型，先做显式映射。
- 存储后的富文本再次展示仍要防 XSS，不能把编辑器当成可信 HTML 消毒器。
