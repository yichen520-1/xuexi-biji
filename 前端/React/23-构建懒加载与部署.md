# React：构建、懒加载与部署检查

> **版本口径**：按指定 React18 课程讲解，示例固定 React 18.3.1、Router 6；与 React19 的差异单独说明。
> **来源边界**：已核验课程分集标题；以下原理、示例与练习为结合官方文档自主编写，不是视频逐字稿。

---

<span style="background-color:rgb(255, 249, 227)">一：概念</span>

开发服务器、生产构建与静态文件服务器是三件事。构建生成部署产物，preview 用于本地查看产物，不应默认充当公开生产服务。路由懒加载减少首屏必须加载的代码，但会引入异步加载与失败状态。

---

<span style="background-color:rgb(255, 249, 227)">二：写法与执行过程</span>

```tsx
import { lazy, Suspense } from 'react';
// ./pages/Report.tsx 需要导出 default 组件
const Report = lazy(() => import('./pages/Report'));
export function ReportPage() {
  return <Suspense fallback={<p>页面加载中</p>}><Report /></Suspense>;
}
```

lazy 声明在组件外，避免每次渲染都创建新组件类型。异步模块通常有 default 导出；若依赖网络失败还需 Error Boundary/重试等策略，fallback 不自动处理所有异常。

| 验收点 | 为什么 |
| --- | --- |
| 入口与深层路由刷新 | 区分服务器路径与前端匹配 |
| base/子路径资源 | 避免部署到子目录后静态文件 404 |
| 环境变量 | 前端打包值可被用户看到，不存秘密 |
| 缓存与更新 | HTML 与 hash 资源缓存策略不同 |
| 包体积分析 | 先定位大依赖，再决定拆分或替换 |

<span style="background-color:rgb(255, 249, 227)">三：对照与易错点</span>

CDN 不自动解决所有性能问题，也会增加可用性、版本一致性和完整性校验要求。不要把任何包都 external 后就认为“体积变小所以更好”。课程使用的构建器与本地 Vite 配置要分开说明，不照搬旧 Webpack 插件名。
