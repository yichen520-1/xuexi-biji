# React：不可变更新与派生状态

> **版本口径**：按指定 React18 课程讲解，示例固定 React 18.3.1、Router 6；与 React19 的差异单独说明。
> **来源边界**：已核验课程分集标题；以下原理、示例与练习为结合官方文档自主编写，不是视频逐字稿。

---

<span style="background-color:rgb(255, 249, 227)">一：概念</span>

React 需要可比较的新状态来描述变化。对 state 数组 push 后再传回同一引用，既破坏旧快照，也可能无法触发预期更新。不可变更新并非“所有东西都深拷贝”，而是沿变化路径创建新对象，未变部分保留引用。

---

<span style="background-color:rgb(255, 249, 227)">二：写法与执行过程</span>

```tsx
import { useState } from 'react';
type Task = { id: string; title: string; done: boolean };
export function Tasks() {
  const [tasks, setTasks] = useState<Task[]>([]);
  const doneCount = tasks.filter(task => task.done).length;
  function toggle(id: string) {
    setTasks(current => current.map(task =>
      task.id === id ? { ...task, done: !task.done } : task));
  }
  return <><p>完成 {doneCount} 项</p>{tasks.map(task =>
    <button key={task.id} onClick={() => toggle(task.id)}>{task.title}</button>)}</>;
}
```

toggle 只为被改任务创建新对象，其他记录沿用。doneCount 完全由 tasks 推导，直接渲染时计算，不额外 useState 再用 Effect 同步。

| 操作 | 常用不可变写法 |
| --- | --- |
| 添加 | `[...current, item]` |
| 删除 | `current.filter(...)` |
| 修改某项 | `current.map(...)`，目标项复制 |
| 排序 | `[...current].sort(...)` |

---

<span style="background-color:rgb(255, 249, 227)">三：对照与易错点</span>

对象展开只浅复制一层；嵌套属性也变化时，要继续复制嵌套路径。不要为了“同步过滤列表”添加一个多余 Effect，多个源状态会渐渐漂移。简单 filter 不必一律 useMemo，先明确正确性，再测量性能。

<span style="background-color:rgb(255, 249, 227)">四：动手练习</span>

页面有原数组、关键词和过滤结果，哪两项是状态，哪一项通常是派生值？

> [!success]- 参考答案
> 原数组与关键词是源状态，过滤结果在渲染时推导。除非结果代表独立外部事实，否则不另存一份。
