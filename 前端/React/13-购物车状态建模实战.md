# React：购物车状态建模与派生统计

> **版本口径**：按指定 React18 课程讲解，示例固定 React 18.3.1、Router 6；与 React19 的差异单独说明。
> **来源边界**：已核验课程分集标题；以下原理、示例与练习为结合官方文档自主编写，不是视频逐字稿。

---

<span style="background-color:rgb(255, 249, 227)">一：概念</span>

购物车至少区分商品目录、购物车行和界面选择状态。购物车行使用稳定商品 id 与数量，价格单位明确为整数分；总数量、总金额是派生数据，不应每点一次按钮就手工维护多套累加变量。

---

<span style="background-color:rgb(255, 249, 227)">二：写法与执行过程</span>

```ts
export interface CartLine { productId: string; priceCents: number; quantity: number }
export function add(lines: readonly CartLine[], productId: string, priceCents: number): CartLine[] {
  if (!Number.isInteger(priceCents) || priceCents < 0) throw new Error('价格无效');
  const exists = lines.some(line => line.productId === productId);
  return exists
    ? lines.map(line => line.productId === productId ? { ...line, quantity: line.quantity + 1 } : line)
    : [...lines, { productId, priceCents, quantity: 1 }];
}
export function totalCents(lines: readonly CartLine[]): number {
  return lines.reduce((total, line) => total + line.priceCents * line.quantity, 0);
}
```

分类选择只决定展示哪些商品，不删除购物车记录。数量减到零时，要有明确规则：移除行或保留禁用状态，不能让负数混进统计。真实下单金额最终由服务器计算并校验，客户端价格不是可信结算依据。

<span style="background-color:rgb(255, 249, 227)">三：对照与易错点</span>

| 数据 | 建议位置 |
| --- | --- |
| 跨页购物车 | store 或明确共享父级 |
| 当前分类 | 页面/路由参数，按是否需分享地址决定 |
| 总金额 | selector/渲染派生 |
| 购物车弹层开关 | 本地 UI 状态，除非有跨页需求 |

货币并不因改成整数分就永远无溢出，超大数值仍要考虑 JS 安全整数范围；本教学案例使用受限金额，不当通用财务系统。

<span style="background-color:rgb(255, 249, 227)">四：动手练习</span>

同一商品连续添加三次，切分类后再回购物车，数量应如何变化？

> [!success]- 参考答案
> 同一 id 的行数量为 3，不是生成三个无关行；分类筛选不应破坏购物车源状态。
