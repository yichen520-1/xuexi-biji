# CSS布局

先理解正常排布，再有意选择布局模型。页面主结构通常用正常流、Flex 或 Grid，角标与覆盖内容再用定位；多列布局与 float 留给适用需求。

## 一：主学习顺序

1. [[前端/CSS/CSS进阶/CSS正常文档流与overflow|正常文档流与溢出]]：先知道默认怎样排。
2. [[前端/CSS/CSS进阶/CSS弹性盒|Flex 基础]]：一维空间分配。
3. [[前端/CSS/CSS进阶/CSS弹性盒布局--主轴和交叉轴|Flex 轴向与对齐]]：基础之后再细看方向。
4. [[前端/CSS/CSS进阶/CSS布局--网格布局基础|Grid 基础]]：建立二维轨道。
5. [[前端/CSS/CSS进阶/CSS布局--网格布局--项目的对齐方式|Grid 项目对齐]]：轨道与格内对齐分开。
6. [[前端/CSS/CSS进阶/CSS布局--定位布局|定位分组]]：先包含块，再绝对定位案例与层叠。
7. [[前端/CSS/CSS进阶/CSS布局--多列布局|多列布局]]：适合连续内容分栏，不是任意二维卡片网格。

## 二：按需求选方法

| 需求 | 优先考虑 |
| --- | --- |
| 正文自然向下排 | 正常流 |
| 工具栏、导航或单轴项目分配 | Flex |
| 有统一行列轨道的卡片/页面区块 | Grid |
| 卡片右上角标、局部覆盖 | 合适的定位 |
| 报纸式连续文章分栏 | 多列布局 |
| 图片旁文字环绕、维护旧代码 | float，不因旧文件标题而认定属性已废弃 |

## 三：完成标准

能解释每个盒子是否参与正常流，指出布局容器与直接项目，说明尺寸和间距由哪条规则控制。页面没对齐时先查模型和占位，而不是连续试不同 margin 或绝对坐标。
