# TS：继承、抽象类与组合

> **定位**：以 JS 为运行基础、C++17 为对照理解静态类型；示例按 TypeScript 5.9.3 验证，不宣称为最新版本。
> **来源边界**：已核验课程分集标题；以下原理、示例与练习为结合官方文档自主编写，不是视频逐字稿。

---

<span style="background-color:rgb(255, 249, 227)">一：概念</span>

继承表达“是某种对象”，接口表达“具有某种能力”，组合表达“持有协作对象”。不要因为 TS 有 `extends` 就把前端状态、接口请求和组件通信都改写成深层继承树。抽象类可共享实现，抽象成员要求子类实现，但 TS 的抽象限制主要发生在检查期。

---

<span style="background-color:rgb(255, 249, 227)">二：写法与执行过程</span>

```ts
interface Logger { write(message: string): void }
abstract class Repository<T> {
  constructor(protected logger: Logger) {}
  abstract all(): readonly T[];
  count(): number { return this.all().length; }
}
class MemoryRepository<T> extends Repository<T> {
  constructor(logger: Logger, private items: T[]) { super(logger); }
  override all(): readonly T[] {
    this.logger.write('读取');
    return this.items;
  }
}
const repo = new MemoryRepository({ write: console.log }, ['TS']);
console.log(repo.count());
```

父类只依赖 Logger 的结构，不依赖某个具体日志类；通过构造函数注入协作能力，测试时可替换。`override` 配合 `noImplicitOverride` 能发现误拼写或父类 API 变化。

<span style="background-color:rgb(255, 249, 227)">三：对照与易错点</span>

| C++17 直觉 | 在 TS 中应怎样修正 |
| --- | --- |
| 多个基类可构建多继承 | class 只有一个直接父类，可实现多个接口 |
| virtual 决定动态分派 | JS 原型方法有自己的动态查找语义，不照搬 virtual 规则 |
| 析构函数管理资源 | 需要显式生命周期与清理函数 |

返回 readonly 数组只限制调用者通过这个类型修改，不会复制内部数组。若要求真正隔离内部数据，可返回副本，并决定元素是否也要复制。

<span style="background-color:rgb(255, 249, 227)">四：动手练习</span>

如何给仓库换一套日志实现而不改仓库代码？

> [!success]- 参考答案
> 构造时传入另一个符合 Logger 的对象。依赖的是最小能力契约，通常比继承一个巨大基类更灵活。
