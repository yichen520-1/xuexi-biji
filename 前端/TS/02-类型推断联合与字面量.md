# TS：类型推断、联合与字面量

> **定位**：以 JS 为运行基础、C++17 为对照理解静态类型；示例按 TypeScript 5.9.3 验证，不宣称为最新版本。
> **来源边界**：已核验课程分集标题；以下原理、示例与练习为结合官方文档自主编写，不是视频逐字稿。

---

<span style="background-color:rgb(255, 249, 227)">一：概念</span>

**类型推断**是检查器根据初始化、上下文和使用关系推测类型，不是变量能随意变类型。`let n = 1` 通常推断为 `number`；`const mode = 'list'` 通常保留为字面量类型 `'list'`。推断不够准确时再写标注，比把所有局部变量都标一遍更清楚。

联合 `A | B` 表示值属于其中一种类型。你只能直接使用每种成员都保证存在的操作；先收窄才能使用特有成员。字面量联合适合有限业务选项，不必为每个状态发明一个类。

---

<span style="background-color:rgb(255, 249, 227)">二：写法与执行过程</span>

```ts
type ViewMode = 'list' | 'grid';
let mode: ViewMode = 'list';
mode = 'grid';

function formatId(id: string | number): string {
  if (typeof id === 'number') return id.toFixed(0);
  return id.trim();
}

const settings = { pageSize: 20, mode: 'list' as ViewMode };
console.log(formatId(12), settings.pageSize);
```

检查器沿控制流看到 `typeof` 的分支，把 `id` 从联合缩为数字或字符串。联合不是同时具有两套 API 的“万能类型”；它表达的是运行时需要辨认的不同可能。

### 2. 容易忽略的推断拓宽

`const settings = { mode: 'list' }` 只禁止重新给 `settings` 这个变量绑定另一个对象，不禁止修改属性，因此 `settings.mode` 通常会拓宽为 `string`。可显式标注对象类型，或用 `as const` 保留只读字面量，再考虑是否真的需要可修改。

---

<span style="background-color:rgb(255, 249, 227)">三：对照与易错点</span>

| 写法 | 实际意思 | C++17 对照 |
| --- | --- | --- |
| `number` | JS 数字，包括非整数与特殊数值 | 不能直接等同 `int` |
| `'ready'` | 仅允许这个字符串值 | 有限枚举取值的用途相似 |
| `string \| number` | 两种可能之一 | 可与 `std::variant` 比较，但 TS 不生成额外包装 |

**避免双重状态**：若 `loading: boolean` 与 `error: string | null` 可组合出不合理状态，下一步应改用可辨识联合，而不只是继续增加布尔开关。

<span style="background-color:rgb(255, 249, 227)">四：动手练习</span>

实现 `formatPrice(value: number | '免费')`。数字保留两位小数，字符串原样返回。

> [!success]- 参考答案
> 先用 `typeof value === 'number'` 分支，数字返回 `value.toFixed(2)`；另一分支自然缩为 `'免费'`。无需断言。
