# HTML--标签补充

### 1. `<div>`（Division，分区/盒子）

- **语义**：没有语义。它就是个纯粹的“容器/盒子”，专门用来划分网页的区域。
- **显示模式**：`block`（块级）。**独占一行**，可以随意设置宽高。
- **典型用途**：网页大结构（头部、导航、主体、底部）、卡片、侧边栏。它是你布局时的“砖块”。
- **C++17 对照（有限类比）**：可以借用 `struct` 或类把相关成员组织起来的思路，理解 `<div>` 对内容的分组；但 `<div>` 是文档元素，不是 C++ 对象或标准库容器。标准 C++17 不提供 DOM 和页面布局能力，位置、尺寸与排版由浏览器和 CSS 决定，不能把它直接等同于某个 GUI 控件。

### 2. `<p>`（Paragraph，段落）

- **语义**：代表一段文字。浏览器和搜索引擎知道“这里是一段正文”。
- **显示模式**：`block`（块级）。**独占一行**，可以设置宽高（但一般用行高来撑开）。
- **典型用途**：写文章、产品描述、页面上的连续文本。
- **⚠️ 关键特征**：浏览器默认会给 `<p>` 加上**上下外边距**（大约 `1em`），所以两段文字之间会自动产生空隙，方便阅读。
- **C++17 对照**：`std::string` 可以保存文字，`std::cout` 可以输出文字，但它们都不会自动建立网页段落或产生 CSS 外边距。`<p>` 同时表达“这是一个段落”的文档语义，并由浏览器按样式排版；标准 C++17 没有直接对应的段落元素，文字存储、输出与网页排版应分开理解。

### 3. `<a>`（Anchor，锚/超链接）

- **语义**：点击后跳转到某个网址、锚点，或触发某个行为。
- **显示模式**：`inline`（行内）。**不独占一行**，并且**默认无法设置宽高**（因为行内元素的大小完全由文字内容撑开）。
- **典型用途**：导航栏、跳转链接、下载文件。
- **C++17 对照（无直接对应）**：C++ 的函数或 Lambda 回调只能帮助理解“用户操作后执行逻辑”这一小部分；`<a href="...">` 还声明了可导航的目标，具有浏览器的链接、键盘访问和历史导航等行为，标准 C++17 没有等价元素。跳转通常用 `<a>`，执行提交、删除等操作通常用 `<button>`，不要把链接直接当成普通函数调用或按钮。

### 📊 三者核心对比表

| 标签 | 语义 | 默认 display | 独占一行？ | 能设宽高？ | 默认样式 |
| --- | --- | --- | --- | --- | --- |
| `<div>` | 无语义容器 | `block` | ✅ 是 | ✅ 可以 | 无，白板一块 |
| `<p>` | 文本段落 | `block` | ✅ 是 | ✅ 可以 | 自带上下 margin |
| `<a>` | 超链接 | `inline` | ❌ 否 | ❌ 不可以 |   |
