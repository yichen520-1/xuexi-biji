## 1. 基础结构

### 标题

行首使用 `#` 表示标题级别，最多六级。

```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 段落、换行与分隔线

段落之间空一行。行末添加两个空格可换行，也可使用 \u003cbr\u003e。

```markdown
这是第一段。

这是第二段。
这一行后面有两个空格  
所以这里会换行。

---
```

## 2. 文本格式

```markdown
**粗体**
*斜体*
***粗斜体***
~~删除线~~
==高亮==
`行内代码`
```

粗体用于重点结论，斜体用于补充说明，删除线用于废弃内容，高亮适合复习标记。高亮是 Obsidian 常用扩展语法。

显示 Markdown 符号本身时使用反斜杠转义：```markdown
\\*这不是斜体\\*
\\# 这不是标题
```

## 3. 列表与任务

```markdown
- 苹果
- 香蕉
  - 国产香蕉
  - 进口香蕉

1. 确定主题
2. 收集资料
3. 整理笔记

- [ ] 阅读文档
- [x] 完成初稿
- [ ] 检查链接
```

在 Obsidian 阅读视图中点击任务复选框即可切换状态。

## 4. 引用与提示

普通引用：

```markdown
> 好的笔记应该帮助未来的自己快速找回上下文。
>
> —— 笔记原则
```

Obsidian Callout：

```markdown
> [!tip] 小技巧
> 给标题和段落之间留出空行，笔记会更容易扫描。

> [!warning]- 注意
> 折叠 Callout 的标题后加 `-`。
```

常用类型：`note`、`tip`、`info`、`success`、`warning`、`danger`、`question`、`quote`。

## 5. 链接、图片与嵌入

```markdown
[OpenAI](https://openai.com)
<https://openai.com>

[[另一篇笔记]]
[[另一篇笔记|自定义显示文字]]
[[另一篇笔记#某个标题]]

![图片说明](https://example.com/image.png)
![[图片.png]]
![[另一篇笔记]]
![[录音.mp3]]
![[文档.pdf]]
```

输入 `[[` 后，Obsidian 会提示仓库中的笔记；不存在的笔记可点击链接创建。

## 6. 代码

行内代码使用一对反引号，例如 `console.log()`。多行代码使用三对反引号，并标注语言：

````markdown
```javascript
function greet(name) {
  return `Hello, ${name}!`;
}
```
````

代码块也可以设置标题：

````markdown
```python title="hello.py"
print("Hello, Obsidian!")
```
````

常用语言标识：`javascript`、`python`、`bash`、`css`、`html`、`json`、`sql`、`cpp`。

## 7. 表格

```markdown
| 语法 | 作用 | 示例 |
| --- | --- | --- |
| `#` | 创建标题 | `# 标题` |
| `** **` | 加粗文字 | `**重点**` |
| `[[ ]]` | 链接笔记 | `[[项目笔记]]` |
```

使用冒号设置对齐：

```markdown
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| A | B | C |
```

表格适合对比参数、记录术语和制作速查表，不适合大段文字。

## 8. Obsidian 专属语法

### 标签

标签以 `#` 开头且不能包含空格：

```markdown
#学习/Markdown
#项目/进行中
```

### 块引用与块链接

```markdown
这是一段可复用的重要结论。 ^important-conclusion
```

引用：

```markdown
[[笔记名称#^important-conclusion]]
```

### 脚注与公式

```markdown
Markdown 最初由 John Gruber 创建。[^1]

[^1]: 这是脚注内容。

爱因斯坦质能方程：$E=mc^2$

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

## 9. 排版建议与常见错误

- 一个笔记围绕一个主要主题。
- 标题层级按顺序使用，不要跳级。
- 段落尽量简短，一段表达一个意思。
- 文件名、标签和标题使用稳定、可搜索的关键词。
- 重要结论可用粗体或 Callout，但不要整页高亮。
- 代码块注明语言，表格保持列数一致。
- 检查链接括号、表格竖线和代码块反引号是否成对。
- 标签不要写成 `# 标签`；中间空格会使其变成普通文字。
- 列表不要过度嵌套，移动端优先保证可读性。

## 10. 高频语法速查表

| 需求 | 写法 |
| --- | --- |
| 标题 | `# 标题` |
| 粗体 | `**文字**` |
| 斜体 | `*文字*` |
| 删除线 | `~~文字~~` |
| 高亮 | `==文字==` |
| 无序列表 | `- 项目` |
| 有序列表 | `1. 项目` |
| 任务列表 | `- [ ] 待办` |
| 引用 | `> 引用内容` |
| 外部链接 | `[文字](网址)` |
| 内部链接 | `[[笔记名]]` |
| 图片 | `![[图片.png]]` |
| 行内代码 | ``代码`` |
| 代码块 | ```语言` |
| 分隔线 | `---` |
| 标签 | `#标签` |
| Callout | `> [!tip] 标题` |
| 公式 | `$公式$` 或 `$$公式$$` |

## 结语

Markdown 的核心是用简单标记表达清晰结构。先掌握标题、列表、链接、代码和 Callout，再逐步增加标签、嵌入、脚注和公式，就能满足大多数 Obsidian 使用场景。
